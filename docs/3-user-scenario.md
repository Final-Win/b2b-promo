# Team WBS 사용자 시나리오

PRD 11절 한 줄 시나리오를 화면/데이터 흐름 기준으로 구체화. MVP 범위(도메인정의서 4/5절, PRD 4/5절)만 다루며, 관리자 전용 화면·알림·주간집계는 제외.

## 1. 일반 회원 시나리오

### 1-1. 로그인
- 목적: 인증 후 캘린더 메인 진입
- 흐름: 로그인 화면에서 이메일/비밀번호 입력 → 서버 인증 성공, Access/Refresh Token 발급 → 캘린더 메인으로 이동
- 완료 조건: 캘린더 메인 화면에 5주 뷰(오늘 포함 주 정중앙)가 표시됨

### 1-2. 일정 확인
- 목적: 본인/타인의 WBS 일정을 캘린더에서 확인
- 흐름: 캘린더 메인에서 각 회원의 WBS 막대(상태별 색상: TODO 회색, IN_PROGRESS/QA 하늘색, RESOLVED/DONE 초록색)를 스크롤/열람
- 완료 조건: 원하는 주차의 WBS 막대들을 한눈에 확인

### 1-3. 일정 등록(WBS 생성)
- 목적: 새 업무를 캘린더에 등록
- 흐름: 캘린더 메인에서 원하는 날짜 구간에 막대를 드래그 → 우측 게시글 상세패널 노출(신규 작성 모드, 시작일/종료일 자동 반영)
- 완료 조건: 상세패널이 열리고 기간이 드래그한 값으로 채워짐

### 1-4. 상세 내용 작성
- 목적: WBS의 세부 정보와 시간 배분 입력
- 흐름: 상세패널에서 제목/내용/담당자 입력 → 일자별 수행시간(1시간 단위) 입력(합산 시간 자동 표시, 8시간 초과 시 경고 표시) → 저장
- 완료 조건: 저장 성공 시 WBS 상태 TODO로 캘린더에 막대 생성, 시간 할당 레코드 저장

### 1-5. 등록 확인
- 목적: 등록한 WBS가 정상 반영됐는지 확인
- 흐름: 캘린더 메인으로 복귀 → 해당 기간에 방금 등록한 막대(TODO, 회색) 노출 확인 → 막대 클릭 시 상세패널에 입력값 그대로 표시
- 완료 조건: 캘린더와 상세패널의 내용이 일치

### 1-6. 내 WBS관리
- 목적: 본인 WBS를 상태별로 한눈에 파악
- 흐름: 우측 하단 "내 WBS관리 탭" 클릭 → 상태값(TODO/IN_PROGRESS/QA/RESOLVED/DONE)별 내 WBS 목록 확인
- 완료 조건: 상태별로 분류된 본인 WBS 목록이 표시됨

### 1-7. 내용 수정
- 목적: 본인이 작성한 WBS의 내용/기간/상태를 수정
- 흐름: 내 WBS관리 탭 또는 캘린더에서 본인 WBS 선택 → 상세패널에서 제목/내용/기간/시간 할당 수정, 상태값 변경(RESOLVED까지만 가능, DONE 선택 시 권한 없음 처리) → 저장
- 완료 조건: 수정 내용이 캘린더 막대와 상세패널에 즉시 반영

### 1-8. 유지/로그아웃
- 목적: 작업 종료
- 흐름: (유지) 별도 조작 없이 세션 유지, Access Token 만료 시 Refresh Token으로 자동 재발급 / (로그아웃) 마이페이지 또는 상단 메뉴에서 로그아웃 클릭 → token_version 증가 → 로그인 화면으로 이동
- 완료 조건: 로그아웃 시 Refresh Token 무효화 및 로그인 화면 전환, 유지 시 세션 끊김 없이 캘린더 사용 가능

## 2. 관리자 시나리오 (예외 동작만, 별도 화면 없음)

### 2-1. 타인 WBS 등록/수정
- 목적: 관리자 권한으로 타 회원 업무를 대리 등록/수정
- 흐름: 관리자 로그인 → 캘린더 메인에서 타 회원 담당 구간에 막대 드래그(또는 기존 막대 클릭) → 동일한 상세패널이 노출, 일반 회원과 동일하게 제목/내용/담당자/기간/시간 입력·수정 → 저장
- 완료 조건: 작성자가 본인이 아니어도 저장 성공, 캘린더에 반영됨(단, 삭제는 작성자 본인만 가능하므로 관리자도 타인 게시글 삭제 버튼은 미노출)

### 2-2. 상태를 DONE으로 변경
- 목적: 완료된 업무를 최종 종료 처리
- 흐름: 관리자가 임의 회원의 WBS를 상세패널에서 열람 → 상태값을 DONE으로 변경 → 저장
- 완료 조건: 상태가 DONE(초록색)으로 반영, 일반 회원 계정으로는 동일 시도 시 권한 없음 처리됨

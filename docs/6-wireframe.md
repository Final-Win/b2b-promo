# Team WBS 와이어프레임

MVP 화면(PRD 5절: 로그인/회원가입/캘린더 메인/게시글 상세패널/내 WBS관리 탭/마이페이지)만 다룸. 관리자 전용 화면은 제외.

---

## 1. 로그인

```
┌─────────────────────────────────────┐
│              Team WBS                │
│                                       │
│   이메일    [_____________________]  │
│   비밀번호  [_____________________]  │
│                                       │
│           [   로그인   ]             │
│                                       │
│        아직 계정이 없으신가요?        │
│           [ 회원가입 ]                │
└─────────────────────────────────────┘
```

- 필드: 이메일, 비밀번호
- 인터랙션: 로그인 성공 → Access/Refresh Token 발급 → 캘린더 메인으로 이동. 실패 시 필드 하단에 오류 메시지(인증 실패)
- 회원가입 링크 클릭 → 회원가입 화면 이동
- 모바일: 폭만 축소, 세로 배치 동일(별도 레이아웃 불필요)

---

## 2. 회원가입

```
┌─────────────────────────────────────┐
│              Team WBS                │
│                                       │
│   이름     [_____________________]   │
│   이메일   [_____________________]   │
│            (형식 검증 오류 시 안내)   │
│   비밀번호 [_____________________]   │
│                                       │
│           [   가입하기   ]           │
│                                       │
│         이미 계정이 있으신가요?       │
│           [ 로그인으로 ]              │
└─────────────────────────────────────┘
```

- 필드: 이름, 이메일(형식 검증), 비밀번호
- 인터랙션: 가입 성공 → 상태 ACTIVE로 계정 생성 → 로그인 화면 이동(또는 즉시 로그인)
- 이메일 형식 오류/중복 시 필드 하단 오류 메시지
- 모바일: 로그인과 동일하게 세로 배치 유지

## 3. 캘린더 메인

- 5주 뷰, 오늘 포함 주가 항상 정중앙(3번째 주)
- WBS 막대 색상: TODO=회색, IN_PROGRESS/QA=하늘색, RESOLVED/DONE=초록색

### 데스크탑

```
┌───────────────────────────────────────────────────────────────────┐
│ Team WBS      [◀ 이전주]   2026년 8월   [다음주 ▶]   [마이페이지▾] │
├───────────────────────────────────────────────────────────────────┤
│      월      화      수      목      금      토      일           │
├───────────────────────────────────────────────────────────────────┤
│ 1주 │  □   │  □   │  □   │  □   │  □   │      │      │  (이전주1)│
├───────────────────────────────────────────────────────────────────┤
│ 2주 │  □   │  □   │  □   │  □   │  □   │      │      │  (이전주2)│
├───────────────────────────────────────────────────────────────────┤
│ 3주 │  □   │ [오늘]│  □   │  □   │  □   │      │      │ ← 오늘 포함│
│     │  ▓▓▓▓ WBS막대(회색:TODO) ▓▓▓▓  │      │      │            │
│     │        ▒▒▒ WBS막대(하늘:진행중) ▒▒▒        │            │
├───────────────────────────────────────────────────────────────────┤
│ 4주 │  □   │  □   │  □   │  □   │  □   │      │      │           │
├───────────────────────────────────────────────────────────────────┤
│ 5주 │  □   │  □   │  □   │  □   │  □   │      │      │  (다음주)  │
└───────────────────────────────────────────────────────────────────┘
                                                    │ (드래그 시 우측
                                                      상세패널 노출) │
                                                    ┌───────────────┐
                                                    │  상세패널      │
                                                    │  (2. 참고)     │
                                                    └───────────────┘
```

- 헤더: 서비스명, 이전주/다음주 이동, 마이페이지 메뉴(로그아웃 포함)
- 그리드: 5행(주) × 7열(요일), 오늘 포함 주는 항상 3번째 행에 고정
- WBS 막대: 시작일~종료일 구간에 걸쳐 그려짐, 상태별 색상 적용
- 인터랙션
  - 빈 날짜 구간 드래그 → 우측 상세패널 신규 작성 모드 오픈(시작일/종료일 자동 반영)
  - 기존 막대 클릭 → 상세패널 조회/수정 모드 오픈
  - 기존 막대 끝단 드래그 → 기간(시작일/종료일) 조정
  - 관리자 로그인 시: 타 회원 막대도 동일하게 드래그/클릭 가능(등록·수정), 단 삭제 버튼은 작성자 본인에게만 노출
- 우측 하단에 "내 WBS관리 탭" 진입 버튼 상시 노출(4번 화면 참고)
- 가로 스크롤 허용(좁은 화면에서 그리드 자체는 축소하지 않고 스크롤로 대응)

### 모바일 (좁은 화면)

```
┌───────────────────────┐
│ ◀ 8월 2026 ▶   ☰      │
├───────────────────────┤
│ (요일/주 그리드,        │
│  가로 스크롤로 열람)     │
│ →→→→→→→→→→→→→   │
└───────────────────────┘
```

- 캘린더 그리드는 가로 스크롤로 대응(별도 축소 레이아웃 없음)
- 막대 클릭/드래그 시 상세패널은 하단 시트로 전환(2. 참고)

## 4. 게시글 상세패널

### 데스크탑 (우측 패널)

```
                              ┌───────────────────────────────┐
                              │  WBS 상세             [닫기 x] │
                              ├───────────────────────────────┤
                              │ 제목   [___________________]  │
                              │ 담당자 [ 회원 선택 ▾ ]         │
                              │ 시작일 [2026-08-11]            │
                              │ 종료일 [2026-08-13]            │
                              │ 상태   [ TODO ▾ ]              │
                              │        (일반회원: RESOLVED까지 │
                              │         선택 가능, DONE 비활성) │
                              │ 내용                            │
                              │ [___________________________]  │
                              │ [___________________________]  │
                              ├───────────────────────────────┤
                              │ 일자별 수행시간                 │
                              │  08-11  [ 4 ]시간               │
                              │  08-12  [ 5 ]시간 ⚠(그날 총 9h) │
                              │  08-13  [ 2 ]시간               │
                              │  이 WBS 합계: 11시간            │
                              ├───────────────────────────────┤
                              │        [ 저장 ]  [ 삭제 ]       │
                              └───────────────────────────────┘
```

- 필드: 제목, 담당자, 시작일, 종료일, 상태, 내용, 일자별 수행시간(1시간 단위, 시작일~종료일 범위만 입력칸 노출)
- "이 WBS 합계"는 입력한 일자별 시간의 단순 합. 8시간 초과 경고는 이 합계가 아니라, **그 담당자가 그 날짜에 투입한 모든 WBS 시간의 합**(서버 daily-sum 조회 결과)이 8시간을 넘을 때만 해당 날짜 옆에 표시(저장은 차단하지 않음)
- 상태값 선택: 일반 회원은 TODO~RESOLVED까지만 선택 가능(DONE 옵션 비활성/미노출), 관리자는 DONE까지 선택 가능
- 삭제 버튼: 작성자 본인에게만 노출(관리자도 타인 글 삭제 버튼 미노출)
- 종료일 < 시작일 입력 시 저장 차단, 오류 메시지 표시
- 탈퇴 회원이 담당자/작성자인 경우 이름 옆에 "(탈퇴)" 표기
- 신규 작성 모드: 캘린더 드래그 구간이 시작일/종료일에 자동 반영, 나머지 필드는 빈 값

### 모바일 (하단 시트)

```
┌───────────────────────┐
│ (캘린더 화면, 상단)      │
├───────────────────────┤
│ ▬▬▬ (드래그 핸들)       │
│ WBS 상세        [x]    │
│ 제목 [_____________]   │
│ 담당자 [ ▾ ]  상태[ ▾ ] │
│ 시작일/종료일 [___]     │
│ 내용 [_____________]   │
│ 일자별 시간 [___]...    │
│ 합계 10h ⚠             │
│ [ 저장 ]  [ 삭제 ]      │
└───────────────────────┘
```

- 좁은 화면에서는 우측 패널 대신 화면 하단에서 올라오는 시트로 전환, 필드 구성은 데스크탑과 동일

## 5. 내 WBS관리 탭

캘린더 메인 우측 하단 버튼으로 열리는 탭(패널 형태).

```
┌───────────────────────────────────────────┐
│  내 WBS관리                        [닫기 x] │
├───────────────────────────────────────────┤
│ [TODO] [진행중] [QA] [해결됨] [완료]        │  ← 상태별 탭
├───────────────────────────────────────────┤
│ TODO (3)                                   │
│ ─────────────────────────────────────────  │
│  · [제목1]        08-11 ~ 08-13            │
│  · [제목2]        08-14 ~ 08-15            │
│  · [제목3]        08-18 ~ 08-20            │
│                                             │
│ (항목 클릭 시 우측/하단에 상세패널 오픈)      │
└───────────────────────────────────────────┘
```

- 상태값(TODO/IN_PROGRESS/QA/RESOLVED/DONE)별 탭 전환, 각 탭에 본인 WBS 목록(제목/기간)만 표시
- 목록 항목 클릭 → 게시글 상세패널 오픈(4번 화면과 동일 패널 재사용)
- 상태별 집계 수치(회원별 주간 할당시간 등)는 2차 범위로 제외, 상태별 목록/건수까지만 표시
- 모바일: 하단 시트 또는 전체화면 오버레이로 전환(패널 폭만 화면 전체 너비로 확장, 구조 동일)

## 6. 마이페이지

```
┌─────────────────────────────────────┐
│  마이페이지                  [닫기 x] │
├─────────────────────────────────────┤
│  이름   : 홍길동                     │
│  이메일 : hong@example.com           │
│                                       │
│              [ 로그아웃 ]            │
│                                       │
│              [ 회원 탈퇴 ]           │
└─────────────────────────────────────┘
```

- 표시: 이름, 이메일(조회만, 수정 기능 없음)
- 로그아웃: token_version 증가 → Refresh Token 무효화 → 로그인 화면 이동
- 회원 탈퇴: 확인 다이얼로그(예/아니오) → 탈퇴 처리 시 상태 WITHDRAWN 전환, 이후 로그인 불가 → 로그인 화면 이동
- 모바일: 동일 구조, 폭만 화면 전체로 확장

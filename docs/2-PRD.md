# Team WBS PRD

## 1. 개요
WBS(업무) 기반 일정 및 작업시간 관리 웹 서비스. 상세 규칙/데이터 모델은 [1-domain-definition.md](./1-domain-definition.md) 참고.

## 2. 목표 / 성공지표
- 목표: 팀원 개인/전체의 WBS를 한 곳에서 캘린더로 관리
- 성공지표: 별도 성과 지표(KPI) 없음 — 사내 사용 도구로, 팀 사용률/사용자 만족도로 정성 평가

## 3. 타겟 사용자
- 초기 10명, 이후 확대 시 최대 100명 규모
- 직무: 서비스기획자, 데이터엔지니어, AI엔지니어, 개발자 등 IT 직무 인원

## 4. 범위 (MVP)

### 포함
- 회원가입/로그인/탈퇴
- WBS(업무) 등록/수정/삭제 (본인 게시글, 관리자 예외 포함)
- 캘린더에서 막대 드래그로 기간 지정 → 우측 상세패널에서 상세 작성
- 상태값(해야할일/진행중/QA/해결됨/완료) 관리
- 일자별 1시간 단위 시간 할당 및 합산
- 내 WBS관리 탭 (상태별 현황)

### 제외 (2차 이후)
- 관리자 화면(회원 관리, 게시글 집계 대시보드) — WBS 관리 화면 안정화 후 진행
- 상태변경/마감일 알림(Teams 연동)

## 5. 화면 목록

| 화면 | 설명 |
|---|---|
| 로그인 | 이메일/비밀번호 로그인, 회원가입 링크 |
| 회원가입 | 이메일/비밀번호/이름 입력 |
| 캘린더 메인 | 5주 뷰(오늘 포함 주 정중앙), WBS 막대 드래그로 생성/기간 조정 |
| 게시글 상세패널 | 캘린더에서 WBS 선택 시 우측에 노출. 제목/내용/담당자/시작일/종료일/일자별 수행시간 입력 |
| 내 WBS관리 탭 | 상태값별 내 WBS 목록 (우측 하단) |
| 관리자 화면 | 회원 관리, 전체 게시글 등록/수정, 집계 확인 (2차) |

## 6. 플랫폼
- 웹 (데스크탑 브라우저 기준). 캘린더 드래그 조작 특성상 모바일 대응은 범위 외.

## 7. 일정
- 1주 내 MVP 개발 (~2026-08-21)

## 8. 알림
- 1차 범위 제외. 추후 상태변경/마감일 Teams 알림 검토.

## 9. 기술 스택
- Frontend: React
- Backend: Node.js
- DB: PostgreSQL
- (초기 프로토타입 단계로 무료 툴 활용)
